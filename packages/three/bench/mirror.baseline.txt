mirror.bench.js on develop at 25d82ad3, the baseline the architecture plan's
regression net asks for (docs/freedom-architecture-plan.md, section 10, tier 2).
A PR under R1, R2 or R6 runs the bench before and after its change and puts
both in its description; this file is what "before" was when the net landed.

The evals, rects and ranges columns count work and are exact: the same code
prints the same numbers on any machine, so a change in one is a change in what
the mirror does. The ms columns are wall-clock on a 4-core cloud container
under Node 22.22.0, and only comparable against a run on the same machine.

Run with, from packages/three:
  node --import ./src/test/setup-jsdom.js src/elements/mirror.bench.js
